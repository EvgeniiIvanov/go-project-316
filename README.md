## Установка

Клонируйте репозиторий и соберите бинарник:

```bash
git clone https://github.com/EvgeniiIvanov/go-project-316.git
cd go-project-316
make build
```

Бинарник появится в `bin/crawler`. Зависимости подтягиваются автоматически через `go.mod`, переменные окружения не требуются.

## Использование

Утилита обходит сайт начиная с переданного URL, следует по ссылкам в пределах того же хоста и выводит отчёт в формате JSON.

```bash
./bin/crawler https://example.com
```

Доступные флаги:

```
--depth int          максимальная глубина обхода, 0 значит только корневая страница (default: 2)
--retries int        количество повторов при неудачном запросе (default: 3)
--delay duration     фиксированная задержка между запросами, например 200ms, 1s (default: 1s)
--rps int            целевое количество запросов в секунду; если задан (>0), имеет приоритет над --delay (default: 0, то есть не используется)
--timeout int        таймаут запроса в секундах (default: 5)
--user-agent string  заголовок User-Agent для запросов (default: "go-crawler/1.0")
--concurrency int    количество параллельных воркеров (default: 5)
--indent             форматировать JSON с отступами
```

`--delay` и `--rps` ограничивают частоту HTTP-запросов глобально для всего процесса обхода, а не по отдельности для каждого воркера: сколько бы горутин ни работало параллельно, интервал между любыми двумя последовательными запросами не будет меньше заданного. Если задан `--rps`, `--delay` игнорируется. Если оба параметра равны нулю (или не заданы), обход не замедляется.

Пример с настройкой глубины и количества воркеров:

```bash
./bin/crawler --depth 3 --concurrency 10 --indent https://example.com
```

Пример с ограничением скорости по RPS:

```bash
./bin/crawler --rps 5 https://example.com
```
